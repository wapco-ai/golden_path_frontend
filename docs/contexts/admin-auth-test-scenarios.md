# سناریوهای تست سشن ادمین و کاربر عمومی

- **ورود ادمین**: ارسال درخواست ورود از صفحه `/admin/login` و انتظار هدایت به `/admin` پس از دریافت `accessToken` و `refreshToken` در استور `gp_admin_*`.
- **دسترسی محافظت‌شده**: تلاش برای باز کردن `/admin` بدون توکن باید به `/admin/login` ریدایرکت شود. پس از ورود، دسترسی آزاد باشد.
- **خروج ادمین**: استفاده از گزینه خروج در نوار کناری و انتظار پاک‌شدن توکن‌ها و هدایت به `/admin/login`.
- **ورود کاربر عمومی (OTP)**: اجرای فلو OTP روی مسیرهای عمومی و ذخیره توکن‌ها زیر پیشوند `gp_user_*` بدون تداخل با ادمین.
- **همزمانی سشن‌ها**: همزمان لاگین بودن کاربر عمومی و ادمین؛ درخواست‌های `/admin/*` باید فقط از توکن ادمین استفاده کنند و درخواست‌های عمومی فقط از توکن کاربر.
- **نقش و دسترسی**: پس از دریافت پروفایل ادمین، بررسی نمایش منوها بر اساس `roles` و `permissions` (توابع `can` و `hasRole`).
