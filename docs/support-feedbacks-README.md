# Support Feedbacks QA Notes

## پیش‌نیازها
- اجرای فرانت‌اند و بک‌اند با `apiBaseUrl` معتبر.
- داشتن حساب ادمین (برای مسیرهای `/api/v1/admin`).

## سناریوهای تست صفحه ثبت بازخورد (Support)
1. صفحه `/support` را باز کنید.
2. فیلدهای Subject و Message را خالی ارسال کنید → باید پیام `fillAllFields` نمایش داده شود.
3. ارسال موفق:
   - Subject و Message را پر کنید.
   - دکمه ارسال باید در حالت loading غیرفعال شود.
   - پس از پاسخ `201`، فرم پاک می‌شود و پیام موفقیت نمایش داده می‌شود.
4. قطع ارتباط با سرور یا timeout:
   - سرور را متوقف کنید.
   - پیام خطای شبکه باید نمایش داده شود.
5. خطای اعتبارسنجی سرور:
   - پیام خطای عمومی اعتبارسنجی نشان داده شود.

## سناریوهای تست پنل ادمین (لیست بازخوردها)
1. ورود به پنل ادمین.
2. باز کردن صفحه بازخوردها:
   - لیست باید از `/api/v1/admin/support-feedbacks` لود شود.
   - فیلتر وضعیت پیش‌فرض روی `new` است.
3. جستجو:
   - در فیلد جستجو تایپ کنید.
   - پس از ~400ms لیست با مقدار جدید فیلتر می‌شود.
4. تغییر وضعیت:
   - وضعیت یک ردیف را تغییر دهید.
   - در صورت موفقیت، وضعیت همان ردیف به‌روزرسانی می‌شود.
   - در صورت خطا، وضعیت به مقدار قبلی برمی‌گردد.
5. صفحه‌بندی:
   - با استفاده از کنترل‌های صفحه‌بندی بین صفحات جابجا شوید.
