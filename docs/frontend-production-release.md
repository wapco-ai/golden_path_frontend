# انتشار فرانت‌اند پروداکشن

منبع انتشار، آخرین کامیت `main` در مخزن `wapco-ai/golden_path_frontend` است. از نسخهٔ محلی همین شاخه، در PowerShell 7 اجرا کنید:

```powershell
git pull --ff-only origin main
pwsh -File scripts/Publish-Frontend.ps1
```

برای بررسی شناسهٔ نسخه به‌تنهایی، `-CheckOnly` را اضافه کنید. انتشار با اتصال SSH موجود در Ubuntu روی WSL به `94.101.176.78` انجام می‌شود. در صورت نیاز، مسیر Chrome را با `-Chromium` مشخص کنید.

اسکریپت از فایل‌های ثبت‌شده در همان کامیت در یک مسیر موقت بسته می‌سازد. آزمون‌های مسیریابی، کش برنامه و آزمون‌های مرورگری انتخاب زبان، بازگشت از جزئیات مکان، QR، پیوست فرهنگی و طبقهٔ نقاط راهنما پیش از انتقال اجرا می‌شوند.

سرور مستقل از رایانهٔ سازنده، `main` فعلی GitHub و ادامهٔ تاریخچهٔ آخرین نسخهٔ منتشرشده را بررسی می‌کند. بسته و ارجاع‌های فایل صفحه و Service Worker با SHA-256 کنترل می‌شوند. هندسه و دستورهای مسیر نمونهٔ هم‌طبقه، بین‌طبقه و درهای یک‌طرفه در دو جهت قبل و بعد از انتشار مقایسه می‌شوند. شکست بررسی پس از جایگزینی، فایل‌ها را از پشتیبان همان انتشار برمی‌گرداند.

ناشر نصب‌شده در `/opt/golden_path_stack/scripts/frontend_release.py` اجرا می‌شود. فایل‌های `index.html` و `sw.js` در حالت عادی روی دیسک محافظت می‌شوند و ناشر هنگام انتشار کنترل‌شده به‌روزرسانی‌شان می‌کند. اطلاعات نسخهٔ فعال در `/opt/golden_path_stack/scripts/frontend-release.json` ثبت می‌شود. تغییر خود ناشر یا اسکریپت بررسی مسیر باید پس از ادغام در `main` با دسترسی مدیریتی روی سرور نصب و آزموده شود.
