# انتخاب طبقهٔ نقشه

دکمهٔ ۵۴×۵۴ انتخاب طبقه زیر تصویر استایل نقشه قرار دارد. منوی طبقات به سمت
چپ باز می‌شود و انتخاب فعلی با رنگ آبی و علامت تیک مشخص است. منوی استایل و
طبقه هم‌زمان باز نمی‌مانند. Escape یا لمس بیرون، منو را می‌بندد.

طبقهٔ نمایش نقشه از طبقهٔ مبدأ و مقصد مستقل است. انتخاب نقطه روی نقشه، طبقهٔ
همان لحظه را در نقطه ذخیره می‌کند. نتایج جست‌وجو تمام طبقات را شامل می‌شوند
و نام طبقه را نمایش می‌دهند. اگر موقعیت GPS یا یک لینک قدیمی طبقه نداشته
باشد، پیش از مسیریابی طبقهٔ آن از کاربر پرسیده می‌شود.

در پیش‌نمایش مسیر و راهنمای حرکت، نشانگر طبقه از مرحلهٔ مسیر پیروی می‌کند
و طبقهٔ مسیر را به صورت خواندنی نشان می‌دهد. تأیید عبور از پله یا آسانسور
همان رفتار موجود راهنمای حرکت را دارد. در صفحهٔ نتیجهٔ مسیریابی، انتخاب
طبقه فقط لایه و قسمت قابل مشاهدهٔ مسیر را عوض می‌کند.

فهرست طبقات از API عمومی با کش پنج‌دقیقه‌ای دریافت می‌شود؛ دادهٔ نقاط نقشه
برای هر طبقه کش جدا دارد. درخواست مسیر به تغییر طبقهٔ نمایش وابسته نیست.

## دریافت تغییرات در Bash / WSL

ابتدا بک‌اند و فایل SQL جدید را دریافت کنید. دستورات زیر با مسیر بک‌اند
اعلام‌شده در این پروژه نوشته شده‌اند:

```bash
(
  set -euo pipefail
  cd ~/work/golden_path_stack/src
  git switch main
  git pull --ff-only origin main
  docker compose up -d --wait db redis

  gp_backup="golden_path_before_public_floors_$(date +%Y%m%d_%H%M%S).dump"
  docker compose exec -T db pg_dump -U postgres -d golden_path -Fc > "$gp_backup"
  test -s "$gp_backup"

  docker compose exec -T db psql -X -U postgres -d golden_path \
    -v ON_ERROR_STOP=1 < db/changes/20260917_180000_public_place_floors.up.sql

  docker compose up -d --build app nginx
  docker compose exec -T app php artisan optimize:clear
  docker compose exec -T app php artisan queue:restart
  printf 'Update completed. Backup: %s\n' "$gp_backup"
)
```

این SQL فقط اطلاعات طبقه را به خروجی جست‌وجو اضافه می‌کند و نیاز به بازسازی
گراف ندارد. فایل‌های SQL قبلی مربوط به اتصال طبقات، که قبلاً اجرا شده‌اند،
بخشی از این مرحله نیستند. فایل `.down.sql` متناظر امکان بازگشت قرارداد
خروجی جست‌وجو را فراهم می‌کند.

سپس در پوشهٔ مخزن فرانت:

```bash
git switch main
git pull --ff-only origin main
npm ci
npm run build
```

برای اجرای محلی Vite، اجرای قبلی را متوقف و `npm run dev -- --host` را دوباره
اجرا کنید. در استقرار وب، خروجی `dist` را با روش معمول پروژه منتشر کنید و
صفحه یا PWA باز را دوباره بارگذاری کنید.

## آزمون‌ها

`npm test` شامل اعتبارسنجی طبقه، حفظ اطلاعات نقاط، جلوگیری از حدس طبقهٔ GPS،
کش و تلاش مجدد API طبقات، لینک QR و پنهان شدن مسیرِ طبقهٔ دیگر است.
`npm run test:browser` سناریوهای واقعی مرورگر را با API آزمایشی اجرا می‌کند:
اندازه و جای دکمه در موبایل، منوها و کیبورد، انتخاب نقطه در طبقات مختلف،
جست‌وجوی نقاط هم‌نام، QR، انتخاب صریح طبقهٔ نامعلوم و راهنمای مسیر.
تست‌های اتصال و مسیریابی واقعی PostgreSQL/PostGIS در CI بک‌اند اجرا می‌شوند.
